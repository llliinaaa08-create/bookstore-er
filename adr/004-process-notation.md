# Вибір Mermaid для діаграми процесу (UC-1)

## Статус
Прийнято

## Контекст
Треба було намалювати схему замовлення (UC-1), розбиту по сервісах, з паралельними кроками та скасуванням товарів. Схема мала легко відкриватися і читатися в Git

## Що розглядали
- **BPMN (Camunda):** Занадто великий XML-файл, у порівнянні кодів на PR нічого не зрозуміло
- **PlantUML:** Гарний варіант, але GitHub не показує схему без додаткових плагінів
- **Mermaid (`flowchart TD`):** Простий код, підтримує доріжки сервісів (`subgraph`) і показує схему прямо на GitHub

## Рішення
Взяли **Mermaid Flowchart**

## Плюси та мінуси
- **Плюси:** Правиться звичайним текстом, видно кожну зміну в PR, працює в GitHub одразу
- **Мінуси:** Простіший вигляд, менше красивих кнопок чи ікон ніж у BPMN
